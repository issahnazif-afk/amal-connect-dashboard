# GitHub upload and launch checklist

- [ ] Create a new GitHub repository.
- [ ] Extract the ZIP file on Windows.
- [ ] Open the extracted folder and confirm `index.html` is at its root.
- [ ] Upload all files and folders inside the extracted project folder.
- [ ] Commit to the `main` branch.
- [ ] Open repository Settings → Pages.
- [ ] Select Deploy from a branch.
- [ ] Select `main` and `/(root)`.
- [ ] Save and wait for deployment.
- [ ] Open the URL shown by GitHub Pages.
- [ ] Test sidebar navigation, search, sample application creation, referral review and CSV export.
- [ ] Keep this public demo free of real participant data.
